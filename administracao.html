Baixar backup

Cria um arquivo JSON com os dados atuais de vendas, despesas, produção, serviços, estoque, movimentações e gado.

Guarde o arquivo em local seguro.
⬆️

Restaurar backup

Restaura os dados a partir de um arquivo de backup criado pelo sistema. Os dados atuais serão substituídos.

Nenhum arquivo selecionado.
🧹

Manutenção do banco

Apaga os dados operacionais de Gado, Vendas, Despesas, Produção, Serviços e Estoque no Firestore e limpa o cache deste navegador. O usuário de login não é apagado.

Para sua segurança, será necessário digitar APAGAR e confirmar novamente.

Conteúdo atual

Quantidade de registros carregados do Firestore neste navegador.
